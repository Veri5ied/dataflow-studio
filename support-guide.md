# Support Guide

## Getting help

- Start with [README.md](./README.md) and `docs/`.
- Search existing issues before opening a new one.
- Provide reproduction details for bugs.

## Bug reports

Include:

- Environment (OS, Node, pnpm versions)
- Steps to reproduce
- Expected vs actual behavior
- Logs or error output

## Feature requests

Include:

- Problem statement
- Proposed behavior
- MVP/phase relevance
- Potential tradeoffs
